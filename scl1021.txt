正規表現について
教材（kaiin_systemフォルダ）の中にあるseiki.phpの43行目を確認
正規表現　（参考書P216.510で使用しているが説明無し）
preg_match()を使用し、マッチ指定と呼ばれる
・使用できる文字数字記号
・文字数
・文章全体か、一部に含まれているか等の指定
を行う為の文字列を用意し、判定する文字列と比較して
マッチする～true
マッチしない～false
の判定を受け取る

マッチ指定を行う文字列
全体を「/～/」の形にし
判定する文字列の1文字目から比較する時は前の「/」の後に「^」を付ける「/^~/」
判定する文字の最後の文字まで比較する時は、後ろの「/」の前に$を付ける「/~$/」
これを組み合わせ、文字列の1文字目から最後の字まで全てを判定する時は「/^~$/」

許可する文字の種類と文字数の指定を「/~」の中に記述
基本形
　[許可する文字]許可する文字数
の形で指定する。但し、メールアドレスの@のように、必ずその文字が必須という時は＠とそのまま書く。


マッチ指定を行う文字列
許可する文字数の指定

[]+　直前の指定文字が１字以上
[]*　直前の指定文字が０字以上
[]{m}　直前の指定文字がm字
[]{m,}　直前の指定文字がm字以上
[]{m,n}　直前の指定文字がm字からn字
で指定する。

例）
8～16文字　[~]{8,16}
20字以内で必須入力　[]{1,20}

許可する文字種の指定
指定を行う時、以下の文字は他の意味として
誤作動する可能があるので、前に「\」を付けてエスケープする。

指定文字　　　\　　.　{　  }　[　　]　+　  *　  $　  ^　-
↓
エスケープ後　\\　\.　\{　\}　\[　\]　\+　\*　\$　\^　\-

php以外では() _ ? < > もエスケープ文章になる事もある。
ブラウザや環境フォントによって、バックスラッシュが￥と表示される。


[]の中に指定する文字・記号等を区切りなしで書いていく
例）a s y　の3種類のみ許可
[asy]
この指定では、内部的に文字コードに変換して許可されており
指定する文字が文字コードで連番となっている時は「-」で
「〇～△」を「〇-△」と指定出来るようになっている。
例）数字の1～9を許可　[1-9]

[]内の指定は1バイト文字(ASCIIコード)の半角英数と半角の記号以外
マルチバイト文字を指定する時は「どの文字コードか」を指定しなければならない。
またPHPではUTF-8以外のマルチバイト文字は非対応となっておりUTF-8のみ使用可能
UTF-8を指定する時は、
/~/u
と正規表現全体を指定している　/~/　の後ろに「u」を付ける。

例）教材　26行目～32行目
	//全角文字チェック例

	$wordmatch = "/^[ぁ-んァ-ヶー々一-龠０-９]+$/u";
	$word = "あア言葉１２佐々木";
	if (preg_match($wordmatch, $word)) {
		echo "<p>文字はマッチした</p>";
	} else {
		echo "<p>文字はマッチしなかった</p>";
	}


1バイト文字の「-」ハイフンを使用した連続文字指定について
小文字半角英[a-z]
大文字半角英[A-Z]
半角数[0-9]
この3つはコード上連番なので「-」を使用して指定可
コード上、小文字英と大文字英の間に記号が複数あるため
小文字英と大文字英の指定は
[a-zA-Z]と分けて指定する。

マルチバイト文字（全角文字）の「-」を使用した連続指定
全角数字[0-9]
全角小文字英[a-z]
全角大文字英[A-Z]
この3つは全角でも連番となっている
ひらがな[ぁ-ん]
カタカナ[ァ-ヶ]
漢字[一-龠]
（音引「－」と繰り返し「々」以外）

メールアドレスの正規表現
今回は
使える記号は、ハイフン、アンダースコア、ドットの3種類
＠の次の文字はドット以外
＠以降に最低ドットが1つ必要
という形式を許可する形で作成
＠以降に最低1つのドットは、
～＠～.co.jp
～＠～.com
等ドメイン部はドットが最低1個は付くため

/^[a-zA-Z0-9]+[a-zA-Z0-9\._-]*　ここまでで、＠以前の指定をしている
「半角英数1文字以上」と「半角英数に記号種が0字以上」の組み合わせとなり
・全体で1字以上
・1字目は記号不可
となっている。

@[a-zA-Z0-9_\-]+\.[a-zA-Z0-9\._\-]+$/";

＠は必須
＠の次はドット以外の記号と半角英数
ドットが1つ必須
1つ目のドット以降はドットも含む記号と半角英数
ドメインにドットが2つ以上ある時用にこちらはドットも許可

マルチバイト文字（全角文字）は記号含め全て許可し、1バイト文字は全てNGとする

/^[^ -~]$/

/~　1文字から
[^~]　[]内の1文字目に^を書くと[]内以外という意味になる

1バイト文字のコード順先頭の半角スペースからコード順最後の半角の波線まで
[^ -~] これで1バイト文字以外という意味になる
$/　最後の文字まで。

パスワードの正規表現での作成

教材37行目
/^[a-zA-Z0-9]{8,12}$/　　半角英数で8～12文字
/[a-z]+/　　^や$を使わず、どこかに半角小文字英が1字以上
/[A-Z]+/　　^や$を使わず、どこかに半角大文字英が1字以上
/[0-9]+/　　^や$を使わず、どこかに半角数字が1字以上

4つを全て満たすと
・半角英数8～12文字
・半角小文字英・半角大文字英・半角数字の3種必須
となる。
