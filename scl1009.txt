データベースに格納されているデータの取得
データの取得はSELECT文で行う
取得するカラムを指定する事が出来る。全てのカラムを取得する時は*で指定する。
カラム指定
　SELECT カラム名1, カラム名2 FROM テーブル名
全カラム取得
　SELECT * FROM テーブル名

SELECT文は
・取得するカラムの指定
・取得するテーブル名
は必須となり、これにオプションで
・取得する行の条件指定（WHERE）
・取得データの並び替え（ORDER BY）
などの指定を必要に応じ追加する。
（今回は行は全て取得の為、WHEREはない）

WHEREでの取得行の絞り込み
WHERE 'カラム名'　比較演算子　値
の形で「〇〇カラムの値が△△のもの」という指定で行う
使える比較演算子は<、>、<=、<=、=、<>
また複数条件を組み合わせても可能AND ORを使用して
'カラム名 >= 50 AND 'カラム名' <= 100
と「50～100のもの」という条件にすることも出来る。

またMySQLデータベースではあいまい検索が可能となっている
・〇〇から始まる文字
・△△で終わる文字
・文中にXXを含文字
など一部一致の形となっている。　
あいまい検索を行う演算子
LIKE　演算子
LIKE演算子を使用し値の方へ以下のワイルドカードを使用する。
%～０字以上の任意の文字
_～任意の1文字のプレースホルダ
を使用する。
例）
カラム名 LIKE "%テレビ%"　　文中に「テレビ」という文字を含む
カラム名 LIKE "__型テレビ"　　〇〇型テレビ（前に任意の2文字）
カラム名 LIKE "テレビ_%"　　テレビから始まり、テレビの後ろに1文字以上あるもの。

並び替えを行う
ORDER BY カラム名 昇順or降順
降順：DESC
昇順：ASC
と指定する。

SELECT * FROM post ORDER BY created_at DESC
SELECT * で全カラム取得、FROM post で postテーブルからとなり、
並び替えは ORDER BY created_at DESC により、投稿日時の新しいものから順に並び替えとなっている。
これは投稿内容のブラウザ表示を新しいものから順に表示する為に行っている。
（ORDER BY id DESC でも同じ結果となるが、ブラウザ表示する日時の方で並び替えを指定している）
データベースに対してSELECT文の実行を指示
$result = mysqli_query($link, $sql);
$sql に入ったSQL文を $link で接続したデータベースに対し実行を指示し、
• SELECT成功時： SELECT文の実行結果（取得データ）はデータベースのSELECT文展開場所に保存され、$result にはその展開場所からデータを1件ずつ取り出すための情報が代入される。
• SELECT失敗時（エラー時）： false が代入となる。
